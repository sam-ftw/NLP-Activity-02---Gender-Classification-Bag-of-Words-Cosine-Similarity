# NLP Activity 02: Gender Classification and Text Similarity

## Overview
This Google Colab notebook explores basic Natural Language Processing (NLP) techniques using NLTK and Scikit-learn.

## Experiments
- **Gender Classification:** Extracts last-letter features from names and trains a Naive Bayes classifier.
- **Bag of Words:** Converts text documents into binary feature vectors using `CountVectorizer`.
- **Feature Exploration:** Experiments with CountVectorizer parameters such as stopword removal and n-grams.
- **Cosine Similarity:** Measures similarity between documents using their vector representations.
- **Visualizations:** Uses bar charts and heatmaps to explore name distributions, word features, and document similarity.

## Libraries
- NLTK
- Scikit-learn
- Matplotlib
- Pandas
- Seaborn

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells sequentially within each experiment.
3. Download the required NLTK names corpus when prompted.

## Learning Outcomes
Understand basic feature extraction, text vectorization, Naive Bayes classification, and document similarity measurement.
